# 法学论证语法（第一版种子）

> 一句话（给法学读者）：法学论文的「章节骨架」通常长什么样（五段结构），写论文时照着搭骨架。

从已精读样本归纳的法学论文论证范式。随 400 篇精读扩充。

## 结构范式（典型 H1 骨架）

法学论文的 H1 结构高度稳定，按功能可归为五段：

1. **问题的提出**（或"问题的缘起/界定"）：指出规范空白、实践困境、理论争议；
2. **正当性/原理分析**：论证某制度或规则的正当性、内在机理、一般原理；
3. **标准/规则建构**：提出认定标准、构成要件、适用规则；
4. **配套规则/制度方案**：配套制度、例外、救济；
5. **结语**：回扣问题，提出立法/司法建议。

对应骨架卡：problem → premises(正当性) → central_claim(标准) → normative_conclusions(配套+建议)。

### 400 篇全量实测（h1_patterns 频次）

- **收尾**："结语" 218 次、"结论" 57 次、"余论" 3 次 —— 法学规范论文以"结语"为主，社科式"结论"是少数；
- **开场**："问题的提出" 103 次、"引言" 102 次、"问题的缘起" 2 次 —— "问题的提出"与"引言"几乎各半；
- 大量论文（尤其制度建构型）无独立"问题的提出"节，问题嵌在引言段；
- 一级标题之外，相当部分论文以题名/制度名直接作 H1（如"证券虚假陈述侵权责任规范模式""个人信息国家保护义务理论"），agent 提取 structure 时应保留这些题名式标题而非强套五段式。

## 命题类型判别（用 signal-lexicon 做候选初判）

| 命题类型 | 判别信号 | 例子 |
|---|---|---|
| problem | 问句、"……困境/争议/缺乏规定"、结构位置在引言 | "问题究竟出在什么地方？" |
| premise | 事实/规范陈述，支撑中心命题，常带"首先/其次/其一" | "侵权行为地包括行为实施地与结果发生地" |
| central_claim | central_claim_markers（"本文主张/应采"）+ 规范词 | "管辖域外网侵应采损害说" |
| evidence_* | evidence 词典（案/条/%/示范法） | "皮克尼案……" |
| counter/literature | counter_intro（"有观点/通说/学界"） | "有观点主张类推适用国内管辖" |
| normative_conclusion | normative 词典（"应当/建议/亟需"）+ 结语位置 | "我国立法应当明确……" |

**原则**：信号词是候选，位置（H1/H2 归属）+ 语义复核才定案。agent 必须读上下文确认，不机械匹配。

## 通说 / 少数说 / 作者立场的判别

法学论文的论证核心是"作者 vs 既有学说"的对立结构：

- **通说**：`通说/主流/多数说/学界普遍` + 作者常用转折词（`但/然而/实际上`）后偏离；
- **少数说**：`少数说/有学者/另有观点`；
- **作者立场**：`笔者以为/本文认为/应采`；
- **具体理论立场**：具名学说（如"访问说/目标说/结果排除说/损害说"）——作者逐一驳斥或吸收。

骨架卡的 `positions[].stance` 必须记录这条立场是"通说/少数说/具体学说"，`author_response` 记录作者是驳斥、限定还是吸收。

### 信号词分类铁律（精读 8 篇后校正）

`counter_intro` 与 `author_turn` 极易混淆，按**语法功能**区分：

| 类别 | 功能 | 典型词 |
|---|---|---|
| counter_intro | **引述他人观点**（第三人称） | 有观点主张/有观点认为/通说认为/学界普遍认为/有学者/少数说/主张……说 |
| author_turn | **作者自己表态或转折**（第一人称或转折连词） | 笔者认为/本文认为/然而/但是/实际上/可见/据此/恰恰相反 |

- "但是/然而"是**转折连词**，一律归 `author_turn`，不归 `counter_intro`；
- 只有"有观点/通说/学界/某学者主张"这类**引述第三人称的标记**才归 `counter_intro`；
- 判断一段话是"反方"还是"作者"，看**谁在说**：引述他人=反方，作者自述+转折=作者立场。

## 证据类型与法学学科的关系

| 学科 | 主要证据 | 典型规范结论 |
|---|---|---|
| 刑法/诉讼法 | 法条 + 案例 | 构成要件重构、程序规则 |
| 民商/经济/知产 | 法条 + 案例 + 数据/比较法 | 规则建构、制度方案 |
| 法理/法律史 | 学说 + 史料 | 理论建构、概念澄清 |
| 宪法行政 | 法条 + 判例 + 原则 | 合宪性方案、权力边界 |
| 国际法 | 公约 + 案例 + 比较 | 规则/进路建构 |
