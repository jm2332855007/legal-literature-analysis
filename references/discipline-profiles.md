# 11 学科论证画像（400 篇全量精读版）

> 一句话（给法学读者）：11 个法学二级学科各自的论证套路（比如刑法重解释论、法理重价值论）。

来源：`data/argument_skeletons/` 400 篇精读骨架卡聚合（`data/semantic_baseline/aggregated.json`）。
**这是全量精读证据，不再是机器词典画像。**

## 读法

- 中心命题类型：central_claim_type 分布（normative 应然 / definitive 定性 / descriptive 描述考据 / causal 因果 / evaluative 评价）；
- 证据特征：六类证据的相对占比（判例/法条/学说/软法/数据/史料）；
- 论证范式：从各学科 semantic_note 归纳的典型走法。

## 各学科

### 法律史（falvshi，n=21）
- 中心命题：descriptive 10 / causal 5 / definitive 4 / normative 1 / evaluative 1 —— **描述+因果考据型**，非应然，与教义学学科形成鲜明反差。
- 证据特征：**史料（archive 100）一枝独秀**，远超判例（57）、法条（66）、学说（44）；几乎无软法（4）。
- 论证范式：以一手史料/档案为证据主轴，先考据概念或制度流变，再归因（causal），少数推向当代规范主张。通说/少数说对立较弱，多采"限定/吸收"而非"驳斥"。

### 法学理论（faxuelilun，n=34）
- 中心命题：definitive 15 / normative 12 / causal 3 / descriptive 2 / evaluative 2 —— **定性/概念建构型最突出**。
- 证据特征：**学说（doctrine 131）最突出**，法条（88）与软法（权威论述/文件 55）次之，判例（51）、史料（30）也有出现。
- 论证范式：概念厘定/体系建构/权威阐释三类并存；以权威论述 + 域外学说为论据，驳斥"西方法学束缚/历史虚无主义"等反方，或对新兴思潮（系统论宪法学、数字人权）作评价性反思。

### 国际法学（guojifa，n=8）
- 中心命题：normative 7 / definitive 1 —— 以应然规范方案为主。
- 证据特征：**判例（case 37）与法条（28）并重**，软法（公约/示范法 18）、学说（14）均衡，史料少。
- 论证范式：特征揭示→冲击诊断→框架/规则建构→中国方案；比较法 + 判例 + 公约，规范结论是规则进路的体系化调适。

### 环境与资源保护法学（huanzi，n=7）
- 中心命题：normative 4 / descriptive 1 / causal 1 / definitive 1 —— 类型多样（含实证因果）。
- 证据特征：**法条（statute 28）突出**，学说（23）、软法（15）、数据（12）次之，判例少（7）。
- 论证范式：现行制度反思→理论正当性证成→实体+程序规范构造；个别采用实证（回归）证成执法威慑的因果效果。

### 经济法学（jingjifa，n=28）
- 中心命题：normative 25 / evaluative 2 / definitive 1 —— 高度应然。
- 证据特征：**判例（case 144）突出**，法条（92）、学说（72）、数据（59）、软法（56）均衡，域外经验丰富。
- 论证范式：问题—定性—风险揭示—规制方案四段，功能主义定性 + 域外判例/实证 + 本土个案，落为多维差异化规制。

### 民商法学（minfa，n=107）
- 中心命题：normative 83 / definitive 18 / descriptive 2 / causal 2 / evaluative 2 —— 应然为主，定性次之（最大样本）。
- 证据特征：**法条（statute 504）与判例（case 473）并重**，学说（282）次之，软法（161）、数据（105）不少。
- 论证范式：从实定法规范出发，先界定概念/正当性基础，再层层推演为可操作的裁判/立法方案，辅以类型化案例落实；法解释学 + 比较法 + 实证（数据）三种范式并存。

### 社会法学（劳动法学）（shehuifa，n=4）
- 中心命题：normative 3 / descriptive 1。
- 证据特征：**法条（statute 21）突出**，数据（10）、判例（9）次之。
- 论证范式：风险描述—政策取向—立法原则—制度设计（立法论递进），规范结论是劳动基准/社会保障/财税的具体制度方案。样本最小，画像暂稳性有限。

### 诉讼法学（susongfa，n=57）
- 中心命题：normative 38 / definitive 7 / descriptive 5 / causal 5 / evaluative 2 —— 应然为主，但含实证描述/因果。
- 证据特征：**法条（statute 204）与判例（case 187）并重**，学说（141）、数据（114）次之；实证（认知实验/面板数据/量化）较突出。
- 论证范式：问题—域外框架提炼—本土化改造—具体制度方案；法条 + 判例 + 实证（访谈/问卷/面板回归）嵌入应然论证，或纯教义学类型化重构。

### 宪法学与行政法学（xianfa，n=68）
- 中心命题：normative 50 / definitive 8 / descriptive 4 / causal 3 / evaluative 3 —— 应然为主，含宪法史叙事（描述/因果）。
- 证据特征：**法条（statute 312）最突出**，学说（179）、判例（180）并重，软法（85）、数据（73）、史料（56）均有。
- 论证范式：类型化实践→客体/概念本质区分→再定位到宪法框架，把权属/制度命题转化为公法义务/基本权利命题；权威阐释与法教义学重构并存。

### 刑法学（xingfa，n=39）
- 中心命题：normative 27 / definitive 6 / descriptive 4 / causal 1 / evaluative 1 —— 应然为主，含实证描述。
- 证据特征：**判例（case 175）与法条（statute 152）并重**，学说（82）、数据（82）次之。
- 论证范式：从实定法/通说出发，驳斥主流观点→提出新论→用类型案例验证规范结论；通说/少数说对立最鲜明（多数立场为"驳斥"）。含方法论反思与实证定量研究。

### 知识产权法学（zhichan，n=27）
- 中心命题：normative 20 / definitive 5 / descriptive 1 / causal 1 —— 高度应然。
- 证据特征：**判例（case 154）最突出**，法条（101）、学说（73）次之，软法（43）、数据（42）、史料（31）均衡。
- 论证范式：比较法 + 规范建构，以既有标准/学说为靶逐一驳斥后提新说，证据以外（域外）判例与示范法/国际公约为主。

## 全量校正说明

本版用 400 篇精读骨架卡的 `central_claim_type` + `evidence_type_counts`（逐条 type 计数，已修复脚注污染）+ `semantic_note` 聚合而成。

关键发现：

1. **中心命题类型分布**（全库 400 篇）：normative 270（67.5%）/ definitive 66 / descriptive 30 / causal 21 / evaluative 13 —— 法学论文以"应然规范命题"为绝对主流，但"定性/定义型"（definitive）与"描述考据/因果型"（法律史、实证论文）是重要的少数派，不可一律按"应然"拆解。
2. **学科论证风格两极**：法律史（描述+史料）与法学理论（定性+学说）是"非应然"高地；民商/经济/知产/国际高度应然；诉讼/环资/刑法混合实证。
3. **证据分布**（全库）：法条 1596 > 判例 1474 > 学说 1049 > 数据 566 > 软法 549 > 史料 301 —— 法条与判例是两大支柱，学说第三，实证数据已成第四大证据源。
