# 法学论文阅读提示词库（法学版）

> 一句话（给法学读者）：读论文用的提示词：逐章精读 / 思维导图 / 复现训练。

> 面向两类读者：**法学研究者**（抓论证结构与学说定位）与**初学者**（有法学通用基础、但无此小方向背景）。


---

## 一、双阶段逐章精读（法学版）

### 1.1 阶段一：识别章节结构（只回 JSON）

```
请通读全文，识别这篇法学论文的章节结构，只返回 JSON，不要输出解释文字。

返回格式：
{
  "chapters": [
    {"id": "ch1", "title_zh": "问题的提出", "title_en": "", "role": "立论"},
    {"id": "ch2", "title_zh": "一、……", "title_en": "", "role": "释义"}
  ]
}

要求：
1. 优先使用论文原文标题；
2. role 只能取：立论 / 驳论 / 释义 / 例证 / 限定 / 过渡 / 回扣（取该章主导功能）；
3. 至少返回两章；结构不清时返回“问题的提出”与“结论”；
4. 若某章是纯制度描述或比较法介绍，role 填“例证”或“过渡”。
```

### 1.2 阶段二：逐章精读模板（替换 {{title_zh}} / {{role}}）

```
请精读论文的「{{title_zh}}」一章（该章主导功能：{{role}}）。

请围绕以下问题组织回答：
1. 这一章在全文论证中起什么作用——承接哪一命题、又为哪一结论铺路？
2. 这一章提出或推进了哪些核心命题（一句一命题，按“前提→结论”列出）？
3. 这一章用了哪些规范依据（法条/司法解释/判例/学说/比较法例），分别支撑哪一命题？
4. 这一章的论证形式是什么（教义学解释 / 利益衡量 / 比较法 / 实证数据 / 历史沿革 / 体系解释）？
5. 初学者读这一章前，必须先掌握哪些术语、制度或规范背景？请用一句话解释每一个。
6. 本章是否存在论证跳步、证据不足或未回应的反方？如有，指出位置与缺口。

输出要求：
- 使用 Markdown，标题从三级标题开始（例如“### 本章作用”）；
- 不寒暄、不重复题目；
- 【研究者模式】额外标注：本章与哪些学者/判例对话、立场是通说/有力说/少数说；
- 【初学者模式】额外给：本章一句话白话总结 + 一个生活化类比；
- 术语首次出现须给中文全称与出处（法条给条文号、学说给作者与文献）。
```

### 1.3 阶段三：独立追问（每问独立读全文，不携带上下文）

```
【追问一：核心贡献】
基于全文，用中文判断本文最核心的贡献是什么，并说明它在学说谱系中的位置：
- 它回应的是通说还是少数说？支持、修正还是推翻？
- 它在方法上有什么增量（新解释路径 / 新制度方案 / 新经验证据）？
- 对实务（裁判、执法、立法）有什么可操作的含义？
输出 Markdown，标题从三级标题开始。

【追问二：局限与未决】
基于全文，列出本文最值得质疑的论证缺口、未回应的反方与未检验的假设：
- 论证缺口：哪一步推导缺中间命题？哪处结论强于证据？
- 未回应的反方：学界最可能的反驳是什么？本文是否正面回应？
- 制度落点：提出的制度方案是否有可操作性、成本与副作用是否被评估？
输出 Markdown，标题从三级标题开始。
```

## 二、思维导图提示词（法学版）

```
# 角色
你是法学论文分析助手，任务是把论文转化为结构化思维导图数据。

# 输出格式（严格遵守）
1. 输出必须是 Markdown 标题 + 无序列表，不要代码块标记；
2. 根节点（#）：论文标题；
3. 一级分支（##）固定为以下四支（法学的“结果”一律写作“规范结论”）：
   - 研究背景与问题
   - 论证方法与结构
   - 规范结论与制度方案
   - 研究结论与意义
4. 可选第五支（##）：与本文对话的学说（列出通说/反方及其关系）；
5. 子节点层级不超过 3–4 层，语言中文，一节点一句判断。

# 各分支的内容规范（法学）
- 研究背景与问题：本领域通说/争议是什么？本文要回应哪个未决问题？（不是“社会背景”）
- 论证方法与结构：教义学解释/利益衡量/比较法/实证/历史；按“前提→命题→结论”列骨架；
- 规范结论与制度方案：本文主张的规范命题（“应解释为…”）+ 制度落点（审查/程序/责任/分级）；
- 研究结论与意义：学说贡献、对实务的影响、局限与未决问题；
- 与本文对话的学说：本文引用/反驳了谁？支持者与反对者各自的主张与分歧点。

# 示例（片段）
# 论X的规范构造
## 研究背景与问题
- 通说认为X应作A解释
- 争议：B说与A说在“构成要件”上对立
- 本文回应：A说无法解释第N条
## 论证方法与结构
- 体系解释：第N条与第M条的关系
- 前提1：…；前提2：…；结论：…
## 规范结论与制度方案
- 规范命题：X应解释为…
- 制度落点：程序上须…
## 研究结论与意义
- 修正通说；实务影响：…
- 局限：未检验…

# 任务
请阅读以下论文全文，按上述格式生成思维导图数据：
```

## 三、复现训练提示词（教人默写一篇文章）

> 用途：不读原文先默写、再对照找差距——这是训练"自己写出同框架论文"的最快路径。
> 四步：骨架提取 → 默写提纲 → 对照核对 → 差异清单。

### 3.1 骨架提取（只抽可复现的结构，不抽观点内容）

```
请从论文中提取“可复现骨架”，只输出结构，不输出观点内容：
1. 研究问题：作者要回应的未决问题（一句）；
2. 核心主张（Aha 点）：本文最反直觉/最有增量的一个判断（一句）；
3. 论证结构：章节 → 命题类型（立论/驳论/释义/例证/限定/回扣）→ 该章要解决的子问题；
4. 规范依据映射：每个核心命题 → 用了哪条法条/判例/学说（只给编号，不给原文）；
5. 关键证据：实证数据/案例的作用（支撑哪个前提）；
6. 制度落点：结论落到哪个制度装置（审查/程序/责任/分级/解释权）；
7. 反方与回应：本文预设了哪些反驳、如何回应（一句一反驳）。
输出 Markdown 表格或列表，供下一步默写使用。
```

### 3.2 默写提纲（不看原文，按骨架写）

```
现在请只依据上面的“可复现骨架”，不看原文，仿写一篇同框架论文的提纲：
1. 你的研究问题（换成你自己的问题，但保持同类型的张力）；
2. 你的核心主张（同构的判断，但不许照搬原观点的内容）；
3. 你的论证结构（章节命题序列必须与原骨架同构）；
4. 每个命题配一条规范依据（可替换为同类型法条/判例）；
5. 制度落点（同类型装置）。
要求：只写提纲与命题句，不展开论述；不得出现原论文的专名、数据、引注。
```

### 3.3 对照核对（回原文逐项对表）

```
请把默写提纲与原论文对照，逐项核对并输出差异表：
| 维度 | 原论文 | 我的默写 | 差异类型（缺/弱/偏/多） | 改进动作 |
维度至少覆盖：研究问题、核心主张、论证结构与命题序列、规范依据、证据、制度落点、反方回应。
最后给出：我的默写最缺的一环是什么？下一步该补哪一章？
```

### 3.4 差异清单（练三遍）

```
把上面的差异表压缩为 3 条以内的“复现清单”，每条写成可执行动作：
- 第 1 遍：只补结构（章节命题序列）；
- 第 2 遍：只补规范依据（法条/判例与命题的对应）；
- 第 3 遍：只补反方回应（预设反驳并回应）。
每遍完成后回复：这次补上了什么、还差什么。
```

## 四、综述 [num] 引用规范（法学版）

```
对综述中所有引用他人观点或结论之处，使用 [num] 标注（如 [1]、[2]；多源用 [1][2][3]），
num 对应本综述所引文献的编号。规则：
1. 引用法条不编 [num]——直接写《XX法》第N条；
2. 引用判例不编 [num]——写“XX案（案号/出处）”；
3. 引用学说、数据、观点一律 [num]；
4. 文末不列参考文献列表——参考文献表按 GB/T 7714-2025 单独输出；
5. 每处 [num] 必须指向真实、可核的文献，禁止编造编号。
```

## 使用方式

- 逐章精读：先跑阶段一拿章节 JSON，再把每章标题/功能填入阶段二模板逐章跑，最后跑阶段三的两个追问；
- 思维导图：一轮生成，验收标准是四个固定分支齐全、结论分支写“规范结论”而非“结果”；
- 复现训练：严格按 3.1→3.2→3.3→3.4 四步，每步单独一轮；
- 综述引用：作为综述稿的生成约束与自检清单（[num] 与法条/判例分开）。
